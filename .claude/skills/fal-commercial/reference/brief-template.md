# Brief template

Fill this with the user before any generation. Every blank is a question to ask, not a
default to assume. Save it as `plan/BRIEF.md`.

```markdown
## Brand and message
BRAND / PRODUCT:        [name, one-line product truth]
WHAT THE VIEWER SHOULD FEEL / KNOW:  [one sentence]
CLAIMS ALLOWED:         [any performance claims? usually none]

## References
STRUCTURE / PACING:     [ad(s) whose rhythm we borrow — pacing and structure only]
LOOK / WORLD:           [3–10 clean, text-free stills or clips of the target look]
TYPE REFERENCE:         [a frame showing the title/caption layout to match]
SOURCE OF REFERENCES:   [who supplied them, and do we have the right to use them as references?]

## Creative
HERO CHARACTER:         [who; wardrobe details that must hold in every shot]
THE DEVICE:             [how the product's effect is shown on screen — e.g. a typed prompt
                         pill plus a cursor click makes a change happen]
TONE / THEME LINE:      ["no limit to your imagination; anything can come true"]
COPY:                   [title, 3–4 split captions, tagline, lockup — or "write options"]
GUARDRAILS:             [must not appear: competitor UI or wording, motifs, likenesses]

## Brand assets
FONT:                   [file path; for a variable font, the weight to use]
END CARD:               [asset file; frame rate; is frame 0 at rest?]
COLOURS:                [hex codes]
WORDMARK RULES:         [e.g. "fal" always lowercase]

## Music and sound
DIRECTION:              [era, genre, instruments, energy curve]
RIGHTS:                 [original score only? any licensed track?]
ENDING:                 [default: score plays straight through and fades; no sting under the logo]

## Deliverables
HERO:                   [length, 16:9 1920×1080, 24 fps]
CUTDOWNS:               [30 s / 15 s / 6 s bumper]
VERTICAL:               [9:16 1080×1920 — crop from hero, or native for wide shots?]
OTHER:                  [stills, GIF, captions file, explainer]

## Budget and schedule
GENERATION BUDGET (fal):   [$ — the ledger cap is set ~3% under this]
CLAUDE BUDGET:             [$ or "report only"]
DEADLINE:                  [when the first review cut and the master are due]

## Approvals
GATE 1 KEYFRAMES:       [who approves, how fast]
GATE 2 ANIMATIC:        [who locks picture on 480p drafts]
GATE 3 EYES + EARS:     [who listens to the mix — the model cannot]
```

## Questions that changed the reference production

- "Which ad is it?" and "No copyrighted songs" both arrived after the first message.
  Ask for the exact reference file and the music rule before Phase 1.
- The font defaulted to its lightest weight because a variable font's default axis value
  was 300. Ask for the weight.
- The end-card asset's frame 0 was at rest, which made a seamless hand-off possible.
  Ask for the asset itself, not a description.
- The reporting scope ("everything before 11:45 AM Saturday") was chosen afterwards.
  Agree up front what counts towards the published cost.
